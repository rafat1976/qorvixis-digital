# Qorvixis Digital — Agency Portfolio Website

> **Turning Ideas Into Digital Reality** | Core Vision, Smart Systems.

A modern, high-converting, production-ready portfolio website for Qorvixis Digital — a premier full-stack software engineering, mobile app development, and enterprise systems agency.

## 🚀 Quick Deploy

### GitHub → Netlify (Recommended)

1. Push this repo to GitHub
2. Connect to [Netlify](https://app.netlify.com)
3. Set publish directory to `.` (root)
4. Deploy — zero build step needed!

### Local Preview

Simply open `index.html` in your browser. No build tools or server required.

## 📁 Project Structure

```
qorvixis-digital/
├── index.html      # Complete website (all sections)
├── styles.css      # Custom styles, animations, glassmorphism
├── script.js       # Interactivity, filters, modals, animations
```

## 🎨 Tech Stack

- **HTML5** — Semantic, accessible markup
- **Tailwind CSS** — Utility-first styling (CDN, zero build)
- **Vanilla JavaScript** — Modular, dependency-free interactivity
- **Lucide Icons** — Clean, modern iconography (CDN)
- **Google Fonts** — Space Grotesk (headings) + Inter (body)

## 📸 Adding Project Screenshots

Each portfolio card has a placeholder comment:
```html
<!-- REPLACE WITH PROJECT SCREENSHOT -->
```

Replace the placeholder `<div>` with an `<img>` tag:
```html
<img src="./screenshots/smartfrs.png" alt="SmartFRS Preview" class="w-full h-full object-cover" />
```

## 📝 Customization Notes

- **WhatsApp number**: Replace `8801XXXXXXXXX` in the HTML with your actual number
- **Facebook link**: Update `https://facebook.com/qorvixisdigital` with your page URL
- **Contact form**: Works automatically on Netlify (Netlify Forms)
- **Colors**: Edit Tailwind config in `index.html` `<script>` block
